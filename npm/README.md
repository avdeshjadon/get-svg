# getsvg

> Discover, inspect, and download SVG assets from Wikimedia Commons right from your terminal.

## Quick Start

You can run `getsvg` immediately without installing:

```bash
npx getsvg
```

Or install globally:

```bash
npm install -g getsvg
```

After installing, both `getsvg` and `get-svg` commands are available:

```bash
# Launch interactive search
getsvg

# Search directly
getsvg search "Amazon"

# Download SVG files directly
getsvg download "File:Amazon logo.svg"
```

## Features

- **Interactive TUI**: Live search, interactive selection, instant vector preview (`V`), bulk downloading.
- **Pure Vector Preview**: Native SVG viewer with infinite mathematical clarity and zoom.
- **Cross-Platform**: macOS (Apple Silicon M-series & Intel), Linux (x64), and Windows (x64).
- **Fast & Zero Setup**: Automatically downloads and runs the optimized native binary for your OS.
